# Leave Management System

A lightweight, browser-based tool for employees to check leave balances and submit leave requests—no spreadsheets, no email chains.

## Features
- Real-time leave balance display (Casual, Medical, Vacation)  
- Date-picker range selection with automatic day counter  
- Reason field for manager context  
- One-click “Apply” submission (stores request in localStorage)  
- Responsive UI; works on desktop & mobile

## Quick Start
1. Clone or download the repo  
2. Open `index.html` in any modern browser  
3. Select leave type, pick dates, add reason, hit “Apply”
